# AI_Book_Analysis
A web application on Flask that performs intellectual analysis of book texts. The system automatically generates short annotations to fairy tales or other texts and performs emotion analysis using the BERT model.

 Features:
- Automatic creation of a short table of contents (summary)

- Analysis of the emotional tone of the text (positive / negative / neutral)

- Convenient interface for loading or pasting text

- Display of results in an understandable format

 Technologies: Python, Flask, BERT, spaCy, HTML, CSS (for the interface)

Project goal:
To show the application of neural networks and NLP (Natural Language Processing) in creating a tool for automatic analysis of literary texts.
